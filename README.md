# 🔐 LastKey Backend

A secure Digital Legacy Management Platform backend built using **Spring Boot**, **Spring Security**, **JWT Authentication**, and **PostgreSQL**.

---

## 📖 Overview

LastKey is a secure digital legacy management platform that allows users to safely store important digital assets such as passwords, documents, notes, and personal information.

The backend provides secure REST APIs with JWT Authentication, encrypted password storage, file upload support, email integration, and PostgreSQL database connectivity.

## ⚙️ Installation

### Clone Repository

```bash
git clone https://github.com/pandeytrayambak1519/lastkey-backend.git
```

### Navigate to Project

```bash
cd lastkey-backend
```

### Install Dependencies

```bash
mvn clean install
```

### Run Application

```bash
mvn spring-boot:run
```

## 🔑 Environment Variables

Configure your `application.properties` or environment variables.

```properties
SPRING_DATASOURCE_URL=

SPRING_DATASOURCE_USERNAME=

SPRING_DATASOURCE_PASSWORD=
```
